# 怎么 spawn 这个 prompt

PowerShell hidden mode(走 user Max 订阅 0 额外费):

```powershell
$wt = "C:\Users\su200\Desktop\{PROJECT}-track-{TRACK}"
$prompt = (Get-Content prompts/02-dev-session-spawn.txt -Raw) `
    -replace '{TRACK}', 'fix-phase1-001-adapter-ledger' `
    -replace '{COMMIT}', '380acd8' `
    -replace '{PROJECT}', 'harness'

$cmdLine = "claude --print --dangerously-skip-permissions `"$prompt`" > resume_log.txt 2>&1"
$proc = Start-Process -FilePath "cmd.exe" `
    -ArgumentList "/c", $cmdLine `
    -WorkingDirectory $wt `
    -WindowStyle Hidden -PassThru
"spawned : PID $($proc.Id)"
```

Bash equivalent(WSL / macOS / Linux):

```bash
WT="$HOME/work/{PROJECT}-track-{TRACK}"
PROMPT=$(sed -e 's/{TRACK}/fix-phase1-001/g' \
             -e 's/{COMMIT}/380acd8/g' \
             -e 's/{PROJECT}/harness/g' prompts/02-dev-session-spawn.txt)

cd "$WT" && nohup claude --print --dangerously-skip-permissions "$PROMPT" > resume_log.txt 2>&1 &
echo "spawned : PID $!"
```

# 监控

Spawn 完后 `claude --print` 会跑 30-60 min(取决于 SPEC 复杂度)。期间:

- `tail -f resume_log.txt`(看 dev session 实时输出)
- `cat tasks/track-{TRACK}/PROGRESS.md`(看 status 字段流转)
- `gh pr list`(等 PR 出来)

撞 hang(progress 30+ min 没变):dispatcher daemon 30s polling 自动兜底 spawn verify。
